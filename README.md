# Homepage
A responsive personal homepage project

## Live Demo
[View the live website](https://odin-homepage-project.netlify.app/)

## About
This project is a personal developer homepage featuring:

* A personal introduction
* A selection of projects
* Social media links
* Contact information
* Responsive layouts for different screen sizes

## Features
* Responsive design for desktop, tablet, and mobile screen sizes
* Custom typography using Google Fonts
* Responsive project grid
* Social media icons with links
* Project previews with descriptions
* Contact section and footer
